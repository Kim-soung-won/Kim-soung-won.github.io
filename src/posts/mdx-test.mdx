## 2. GitHub Flavored Tables

`remark-gfm` 플러그인 덕분에 GitHub 스타일의 테이블을 사용할 수 있습니다.

| 기능 | 상태 | 설명 |
| :--- | :---: | :--- |
| 다크 모드 | ✅ | 시스템 설정 및 토글 지원 |
| MDX 지원 | ✅ | React 컴포넌트 임베딩 가능 |
| 검색 기능 | 🚧 | 개발 예정 |
| 댓글 시스템 | ❌ | 미지원 |

## 3. Code Blocks & Highlighting

TanStack 스타일의 어두운 테마가 적용된 코드 블록입니다.

```tsx
// src/components/Example.tsx
import { useState } from 'react';

export function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button 
      onClick={() => setCount(prev => prev + 1)}
      className="bg-red-500 text-white px-4 py-2 rounded"
    >
      Count is {count}
    </button>
  );
}
